# Disease_Outbreak_Prediction

Find this hosted in streamlit at https://diseaseoutbreakprediction-fcr3kohoptz6kvyy2j8hfs.streamlit.app/

## Project Description
This project implements a robust machine learning framework designed to predict the likelihood of three major health conditions: Heart Disease, Diabetes, and Parkinson’s Disease. By leveraging diagnostic datasets and comparative model analysis, the system identifies the most accurate algorithm for each specific condition to ensure reliable predictions.

## Key Features
Multiple Disease Support: Separate diagnostic modules for Heart Disease, Diabetes, and Parkinson's.

Model Benchmarking: Implements and compares several algorithms, including Logistic Regression, Random Forest, Decision Trees, and Support Vector Classifiers (SVC).

High Accuracy: Achieved up to 98% accuracy for Heart Disease and ~90% for Parkinson’s using optimized SVC models.

Data Pipeline: Includes comprehensive data preprocessing, feature scaling using StandardScaler, and feature importance visualization using XGBoost.

Predictive System: Built-in functionality to process custom user input and provide real-time diagnostic feedback.

## Technical Stack
Language: Python
Libraries: Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn
Deployment Ready: Includes an app.py and requirements.txt for web-based integration, deployed on streamlit.
